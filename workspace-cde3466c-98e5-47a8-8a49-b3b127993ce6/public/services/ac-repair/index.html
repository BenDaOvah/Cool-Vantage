Useful answers

Before you call

How do I know if my AC needs repair?+

If the system is blowing warm air, running constantly, leaking water, tripping a breaker, or making a new sound, it is time to call for a professional assessment.

Should I keep running an AC that is leaking?+

Turn the system off if water is accumulating or the unit is icing up, then call for service. Continuing to run a compromised system can make the issue harder to diagnose.
